# Dataset

This project uses the **Online Retail Dataset**, which contains transactional data from a UK-based online retailer between **December 2010 and December 2011**.

## Source

- **UCI Machine Learning Repository:**  
  https://archive.ics.uci.edu/ml/datasets/online+retail

- **Kaggle:**  
  https://www.kaggle.com/datasets/carrie1/ecommerce-data

## Dataset Information

- **Rows:** 541,909
- **Columns:** 8

## Note

The dataset is not included in this repository because it exceeds GitHub's file size limit. Please download the dataset from one of the above sources and place it in the `data/` folder before running the notebooks.
